카카오톡 1:1 대화 내보내기 파일로 두 사람의 이야기를 보여 주는 웹앱이에요.

- 대화는 **서버로 보내지 않아요.** 모든 분석은 내 기기(브라우저) 안에서만 해요.
- 이 사이트는 화면 파일만 내려 주는 정적 사이트예요. 받는 서버가 없어요.
- 페이지에 통신 차단 설정(CSP `connect-src 'none'`)이 들어 있어 어떤 서버로도 데이터를 보낼 수 없어요.

아이폰: 사파리로 열고 공유 → 홈 화면에 추가.
